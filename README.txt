민트은행 3D 1인칭 프로토타입 v2

index.html을 Chrome 또는 Edge로 열면 바로 실행됩니다. 외부 라이브러리·인터넷 연결이 필요 없습니다.
휴대폰: 파일을 다운로드하여 HTML 파일을 브라우저로 여세요. 휴대폰의 파일 열기 방식에 따라 미리보기에서 실행되지 않을 수 있습니다. 이 경우 아래 로컬 서버를 사용하세요.
윈도우: Python 설치 후 이 폴더에서 터미널을 열고 python -m http.server 8080 --bind 0.0.0.0
같은 와이파이의 휴대폰에서 http://컴퓨터의로컬IP:8080 접속. 윈도우 방화벽은 개인 네트워크에서만 허용.
start_windows.bat은 Python으로 서버를 시작하고 PC 브라우저를 엽니다. 외부 인터넷 공개 설정은 하지 않습니다.

가로화면 / WebGL 지원 브라우저 필요.
왼쪽 스틱 이동 / 오른쪽 화면 드래그 시선 / 가운데 고객 응대 버튼.
PC: WASD, 방향키, 화면 드래그, E.
고객 6명마다 영업일 진행. 경험 120에 여신 담당, 300에 지점장.
대출 심사: 신용 700 이상 + 소득 증빙. 잘못 승인하면 결산수익 감소.
종료일 없음. 로컬 저장. 파일 위치 또는 브라우저가 바뀌면 저장이 공유되지 않습니다.

구현: 실제 WebGL 3D 공간, 가구, 캐릭터, 조명 음영, 충돌, 이동, 시선,
예금 업무, 간단한 대출 심사, 승진, 영업일 결산, 자동저장, 효과음.
미구현: 지점장 직원 고용, 은행 확장, 고객 보행 애니메이션, APK 패키징.
기존 PWA의 소스 수정본이 아닌 합의한 방향에 따른 독립적인 새 프로토타입입니다.
